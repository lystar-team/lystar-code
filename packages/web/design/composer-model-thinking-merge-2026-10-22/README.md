## 已确认的设计

1. 交互采用方案 B：浮层首屏两行入口（`模型` / `思考强度`），各自进入列表；列表左上角返回箭头 + 标题。
2. 输入框右下角的入口同时显示模型与当前档位：`GPT 6.1 Sol`（正文色）+ `高`（次要色）+ 一个向下箭头。
3. 会话统计移出输入框，放在输入框下方的信息带里；信息带与输入框共边，底角圆角与输入框顶部一致。
4. 上下文使用率圆环保留在输入框内工具行，位于合并入口左侧。
5. Prompt 输入文字从 13px 提到 14px / 20px；文字叠层共用同一规格。

## 规格

### 输入框内工具行

| 对象 | 规格 |
| --- | --- |
| 左端 | 附件按钮：无边框的圆形按钮，20px 加号图标，命中区 32px（保持现状） |
| 右端顺序 | 上下文使用率圆环 → 合并入口 → 快速模式 → 发送 / 停止按钮 |
| 合并入口 | 高 32px（`h-8`），ghost 无边框，左右内边距 4px（`md` 6px），内容间距 4px；模型名 13px 正文色，单行截断（`max-w-40` 160px；`@container/composer` < 32rem 时 `max-w-24` 96px）；档位 13px `--text-muted`，不截断；`ChevronDown` 12px 一个 |
| 合并入口状态 | 关闭透明底；悬停或打开用 `--accent`；`aria-expanded` 反映浮层；禁用时不显示打开态；`aria-label` 为「模型与思考强度：模型名，档位」或「模型：模型名」 |

### 浮层

| 对象 | 规格 |
| --- | --- |
| 外壳 | `side="top"`、`align="end"`、`sideOffset=8`，宽按内容自适应（入口行与档位列表宽 320px，模型列表按内容），圆角 16px，边框 `--line`，阴影 `0 8px 28px rgb(0 0 0 / 0.12)`，内边距 0 |
| 入口行 | 宽 320px，高 44px，左 13px 正文色标签，右侧 `--text-muted` 当前值，最右 16px 右箭头；两行之间 1px `--line` |
| 列表标题行 | 高 44px，返回箭头（命中区 28px）+ 13px 正文色标题，行下 1px `--line` |
| 模型列表 | 既有内容：搜索行（`搜索模型…`）→ 按 provider 分组 → 条目右侧勾选当前模型；条目 13px，左内边距 8px |
| 档位列表 | `role="radiogroup"`，条目高 32px、13px、圆角 4px、内边距 8px；当前档位右端 16px 勾选，并作为唯一 Tab 停靠点；方向键 / Home / End 在该组内移动焦点，`Enter` / `Space` 选中并关闭浮层 |
| 档位来源 | `visibleThinkingLevels(模型 supportedThinkingLevels)`，文案取 `THINKING_LEVEL_LABELS`；模型不支持 reasoning 时不渲染入口行和档位列表 |
| 视图行为 | 每次打开都从入口行开始；关闭时重置视图并清空模型搜索；`/model` 命令直接进入模型列表并预填搜索 |
| 颜色 | 只用 `--bg-elevated`、`--line`、`--text`、`--text-muted`、`--accent`、`--brand`；勾选继承正文色，与模型列表一致 |

### 输入框下方的统计信息带

| 对象 | 规格 |
| --- | --- |
| 位置 | 输入框外、输入卡片正下方；与输入卡片共边（`margin-top: -1px`，共用一条 1px 边框）；宽度与输入卡片一致 |
| 圆角 | 上边不设圆角，底角与输入卡片顶部一致：支持 `corner-shape: squircle` 时为 48px，否则 `var(--radius)` |
| 表面 | `--muted` 25% 混合底色，1px 边框 `--line`，阴影 `0 2px 12px rgb(0 0 0 / 0.05)`；输入卡片在有信息带时底角改为直角并让出阴影 |
| 内边距 | 上下各 10px，内容行高 28px（信息带高约 50px） |
| 内容 | 四项居中：`平均 TPS`、`缓存命中`、`输入`、`输出`；12px，标签 `--text-muted`，数值正文色 + 等宽数字；条目内边距 6px、间距 2px，不加分隔符号 |
| 缺失值 | 显示 `—`，不填假数据 |
| 收起行为 | 宽度不足时按现有机制逐项收起，优先保留 `平均 TPS`；未显示的指标通过行尾「统计」入口查看；每个指标仍可点开详情浮层 |

### Prompt 输入文字

`packages/web/src/components/ai-elements/prompt-completion-menu.tsx` 的 `PROMPT_TEXT_GEOMETRY_CLASS`：14px / 20px（原 13px / 20px）。输入框与文字叠层共用该规格。

## 状态与适配

- 模型不支持 reasoning 或可见档位 ≤ 1：不渲染 `思考强度` 入口行，入口只显示模型名。
- 无会话、会话不可写、会话未就绪：合并入口禁用。
- 内联编辑历史 Prompt 与智能体协作房间不渲染该入口（现状不变）。
- 窄屏：信息带同样位于输入框下方，不放进输入框，也不占用输入框右上角。

## 已验证（开发实例 http://127.0.0.1:2420，接入运行中的 Gateway）

- 入口显示 `GPT 6.1 Sol 高` 且只有一个箭头；浮层打开后为两个入口行。
- 模型列表可搜索（输入 `claude` 只剩 1 项）与分组展示；返回箭头回到入口行。
- 思考档位列表 6 项，`高(High)` 勾选；方向键在组内移动焦点；`aria-checked` / `tabIndex` 正确。
- 在模型列表输入搜索后切到档位列表，档位不被过滤（已修：档位列表不再共用 cmdk 过滤）。
- `Esc` 关闭浮层并把焦点交回入口；重新打开回到入口行，搜索已清空。
- 信息带与输入卡片共边（元素位置相差 1px）、底角 48px、内容居中；宽度不足时「统计」入口接管。
- Prompt 输入框实测 14px / 20px。
