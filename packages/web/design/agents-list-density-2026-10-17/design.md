## 列表页结构

页头：左“智能体”24/32、600；右侧“协作昵称”“刷新”“新建智能体”同高 32，间距 8。刷新为 32×32 图标按钮，新建为主按钮。

筛选行：左搜索框 320×36，左内边距 36 容纳 16px 搜索图标；右侧范围页签“全部 / 个人 / 项目”，各自带数量徽标。搜索框与页签垂直居中，页签靠右。

选择行：左侧 16px 复选框、12px“全选”、12px 计数；右侧“批量设置”12px、高 28。该行只在有可修改项时显示复选框，否则只显示计数。

表头：高 36、`--bg-soft` 底、12/18、`--text-muted`，列头与下方单元格左对齐。表头固定在列表滚动区顶部，只保留 1px 底边。

表格行：整行 72，上下内边距 14。第一列为复选框 16，垂直居中。名称行 14/22、500，前置 16px 线性图标。描述 12/18、`--text-muted`，单行截断，`title` 提供全文。有擅长标签时在其下以 11/16 文本展示，整行增高到 88；当前 7 个配置没有标签，按 72 展示。

列宽（内容区 1136）：选择 32、名称与职责 468、范围 64、模型 260、工作区 96、工具 96、操作 120。列宽含单元格内边距，名称列最小 320。模型列单行等宽显示 `provider/model`，溢出截断，完整值进 `title`；思考强度作为第二行 12px 辅助文字。范围、工作区、工具均为 12px，不放大。

操作列：“编辑”12px 幽灵按钮，高 28，宽随文字；三点更多为 28×28 图标按钮，间距 4，整体右对齐。删除只在下拉菜单内，不在行内出现。

行状态：悬停使用 `--accent`，选中使用 `--bg-soft`；键盘焦点 2px `--ring`，聚焦整行的“编辑”入口。禁用项复选框与更多菜单不响应，保留“查看”文字。

## 视觉与颜色

沿用项目 token：页面 `--bg`、表头与选中 `--bg-soft`、分隔 `--line`、次要文字 `--text-muted`、主按钮 `--primary` 配白字、焦点 `--ring`。不使用渐变、彩色边条、卡片阴影或指标块。

层级只靠字号、字重与颜色：页面标题 24/600 → 名称 14/500 → 列数据 12/400 → 辅助 12/muted。任何列数据都不使用 14px，任何行内动作都不使用 14px 中等字重。

## 适配

768～1199：侧栏 224、内容水平留白 24。表格改用两段式：名称与描述占主行，范围、模型、工作区、工具合并为 12px 副行；操作列保留“编辑”和更多。筛选行允许页签换到搜索框下一行，间距 8。

小于 768：内容水平留白 16。筛选行上下排列，页签靠左；选择行保留全选与计数，批量设置靠右。列表行改为：复选框与名称同一行，描述一行截断，副行显示范围、工作区、工具和模型；操作列“编辑”与更多保持 44px 命中区。页头三个入口在标题下方一行，不横向滚动。

## 实现记录

已按本稿修改 `settings/subagents.tsx`，并让 `WorkbenchTabOption.icon` 可选（现有传图标调用不变）。

实际采用：标题 24/32；页头按钮 13/32；搜索框 320×36、桌面 14px；范围筛选 `WorkbenchTabBar` 的 navigation 外观，32 高、13px、无外框、无图标，数量用 10px 徽标；选择行 28 高；表头 36 高；行高实测 73px（最小 72）；列数据 12/18；行内动作 12、28 高。列宽按 32 / minmax(320,1fr) / 64 / 260 / 96 / 96 / 120 实现。

全局 `button, input, textarea, select { font: inherit }` 会覆盖字号工具类，页头按钮、名称、搜索框原先分别被当成 16px。本页用 `!text-[13px]`、`!text-sm`、`md:!text-sm` 保持设计字号，与项目 `WorkbenchTabBar` 的 `!text-xs` 写法一致；未改全局规则。

实测：1440×1000 与 390×844 无页面横向溢出；390 下页头改为两行、行内动作横排、行高 105；筛选切换、搜索、空结果均为真实数据。`npm run check` 通过；6 个相关测试文件 31 项通过，未新增测试。截图见 `02-implemented-desktop.png` 与 `03-implemented-mobile.png`。
