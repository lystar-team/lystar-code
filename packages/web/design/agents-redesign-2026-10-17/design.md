# 智能体设置设计确认稿

日期：2026-10-17。阶段：Yean 已确认设计，已完成实现。示例名称和配置取自用户截图；数量用于设计示例。图片表达结构，精确实现规格以本文为准。

## 页面与任务

管理页先查找、比较和选择智能体。卡片改为列表，列为选择、名称与描述、范围、模型、工作区、工具、操作。保留新建、刷新、多选、批量设置和删除。昵称库移到页头“协作昵称”入口，点击后打开独立短表单，保留添加、移除、恢复默认和保存；保存对新加入成员生效。

点击名称或“编辑”在当前设置内容区进入独立编辑视图，顶部“返回智能体”返回原列表并保留搜索、范围筛选和滚动位置。沿用现有设置状态切换，导航无需新 URL。未保存离开时提供继续编辑、放弃修改、保存并离开。新建复用编辑视图，范围可选个人或项目，编辑时范围保持原有不可更改规则。不可编辑配置显示只读状态并保留查看入口。

编辑视图顶部始终显示返回、名称、保存状态、取消和保存。编辑分区为“职责与提示词”“运行配置”“工具权限”“技能”。分区切换保留同一份草稿，不触发保存。错误在对应字段处显示；保存失败保留全部输入，保存中禁用重复提交，成功返回原列表。在提示词编辑器中按 Ctrl/Cmd+S 保存整份配置。

职责与提示词：第一行图标、名称和范围；随后描述、擅长标签；下方以主要空间展示 PROMPT.md 的 Markdown 编辑器。图标入口保留内置图标和上传 SVG。描述和提示词使用截图中已存在内容。

运行配置：集中供应商、基础模型、思考强度和工作区模式。供应商及模型保留继承当前会话，思考强度保留继承模型设置；模型改变后展示其支持的档位。工作区模式完整读取项目现有选项与说明，不新增或遗漏模式。页头按保存后的配置显示摘要，切换分区仍可识别编辑对象。

工具权限：先选规则“沿用默认工具”“仅允许所选工具”“禁用所选工具”，再选择工具。第一项对应现有空列表行为，其余对应 tools / excludeTools，不新增后端权限含义。默认模式显示默认工具且不可勾选；限定允许模式中零项时明确提示沿用默认，不能暗示禁止全部。禁用模式勾选含义始终为禁用。工具列表提供搜索、全部/已选择筛选；每行展示复选框、原始工具名、短用途和生效含义。长描述按需展开且自然换行。切换规则保存各模式草稿，提交按当前规则写入。截图展示“禁用所选工具”且选中 session_create 和 create_agent 的示例。

技能：选择“沿用项目技能”或“仅加载所选技能”，对应现有空列表与非空列表语义。提供搜索、全部/已选择筛选，列表展示原始 Skill 名和描述，长描述换行并可展开全文。零项时明确沿用项目配置；当前无可选项时显示真实空状态。中英文名称和说明保持原值，不编造翻译。

批量设置：多选后显示“已选择 N 个”和“批量设置”；保留现有运行配置与工具权限两个分区，只覆盖本次设置的字段，工具列表修改仍替换原配置。部分失败保留逐项原因和重试未保存项。

## 适配

768～1199 宽度：设置侧栏保留224，内容水平留白24；编辑页签横向可滚动；字段可降为单列。列表使用名称主行加模型和权限副行，操作保留。

小于768：设置分类沿用横向导航，内容水平留白16；列表改为纵向行，范围与摘要放名称下面，编辑和更多保留44高命中区；批量操作靠近选择结果。编辑时返回和保存固定顶部，字段单列、范围全宽、正文编辑器最小320高。工具名、Skill名和说明自然换行，不出现页面水平滚动。

## 工具展开与 JSON 行为（实现阶段）

工具靠近对话视口底部时，主动展开后在高度测量完成后滚动，使详情起始内容可见；详情超过视口时保留标题和开头，不直接跳到长输出末尾。已处于底部跟随状态时随新增内容保持底部；用户向上阅读则不持续抢滚动。JSON 节点展开也纳入相同测量与可视区处理。

JSON 对象和数组逐层独立展开/折叠，保留父子缩进、数组索引和类型值，折叠显示项数。提供全部展开、全部折叠和复制原文；字符串、数字、布尔与 null 按实际类型显示。大 JSON 沿用现有虚拟化和内容加载能力处理；非 JSON 继续按原始输出类型展示。
