# 输入区紧凑化与思考档位直达（2026-10-27）

对象：`packages/web` 底部输入区。
状态：设计稿第二版，待确认后实现。

## 问题

1. 入口 → `思考强度` 行 → 档位，切一次档需要 3 次点击，且每次打开都从入口行开始。
2. 统计信息带横跨整个输入卡片，视觉重量超过内容本身；空闲时还显示一排 `—`。

## 方案

| 对象 | 决定 |
| --- | --- |
| 浮层结构 | 首屏直接放模型搜索与列表；`思考强度` 放在模型列表下方，与入口相邻 |
| 思考档位 | 点击即生效并关闭浮层，切档 2 次点击完成 |
| 模型列表 | 首屏可见，选择 2 次点击完成；保留搜索、provider 分组、当前项勾选 |
| 会话统计 | 保留现有信息带的形态、位置和共边关系，宽度收到内容宽度并居中 |
| 空闲无数据 | 不渲染统计信息带，不显示 `—` 占位 |

预期：切档与切模型从 3 次点击降到 2 次；统计带从整行宽收到内容宽，高度 50px → 40px。

## 图

`composer-compact-v2.png`：上为默认收起态，下为浮层展开态。图为设计示意，比例允许偏差，实现以本文规格为准。

已知图片偏差：

- 图中模型入口只显示模型名和一个箭头，漏了档位文字。实现保持单个箭头，模型名后直接显示档位，即 `Deepseek V4.1 Flash 最大` + 一个 `ChevronDown`。
- 图中浮层底部多了一个小三角指针，档位也没有画出外层轨道底色。实现不画指针，档位使用带 `--bg-soft` 轨道的分段控件（见规格表）。

## 规格

### 收起态：输入卡片

| 对象 | 规格 |
| --- | --- |
| 卡片 | 宽与对话区一致（最大 1280px），圆角 48px（支持 `corner-shape` 时 squircle），边框 0.5px `--line`，底色 `--bg`，阴影 `0 2px 12px rgb(0 0 0 / 0.05)` |
| 内部顺序 | 运行状态行 → Prompt 输入区（14px / 20px）→ 工具行（h-8，上下内边距 8px） |
| 工具行 | 左端附件按钮、右端 ContextRing → 模型与思考入口 → 快速模式 → 发送 / 停止按钮，顺序与尺寸不变 |

### 统计信息带

| 对象 | 规格 |
| --- | --- |
| 位置 | 输入卡片正下方，水平居中，与卡片共边（`margin-top: -1px`，共用一段边框） |
| 宽度 | 内容宽度，约 420px；窄屏不超过卡片宽度，超出时按收起规则处理 |
| 高度 | 上下内边距 6px + 内容行高 28px，共 40px |
| 圆角 | 上边不设圆角；底角 20px（支持 `corner-shape: squircle` 时沿用） |
| 表面 | `--muted` 25% 混合底色，0.5px 边框 `--line`，不额外加阴影 |
| 内容 | 四项居中：`平均 TPS`、`缓存命中`、`输入`、`输出`；12px / 16px，标签 `--text-muted`，数值 `--text` + 等宽数字 |
| 条目 | 行高 28px，左右内边距 6px，条目间距 2px；不加分隔符号 |
| 数值 | 沿用现有格式化：TPS 一位小数，缓存命中整数百分比，输入输出 M / K 缩写 |
| 收起 | 宽度不足时按现有机制逐项收起，优先保留 `平均 TPS`；未显示的指标通过行尾 `统计` 入口查看 |
| 空状态 | 无 usage 且无运行数据时整条信息带不渲染 |
| 详情 | 每项仍可点击，详情浮层朝输入框上方展开，内容不变 |

### 展开态：浮层

| 对象 | 规格 |
| --- | --- |
| 外壳 | 宽 320px，`side="top"`、`align="end"`、`sideOffset=8`；圆角 16px，边框 0.5px `--line`，阴影 `0 8px 28px rgb(0 0 0 / 0.12)`，内边距 8px |
| 分区顺序 | 搜索 + 模型列表（可滚动）→ 0.5px 分隔线 → `思考强度` 标签 + 档位分段控件（固定在底部，不随列表滚动） |
| 搜索 | 高 32px，圆角 8px，`--bg-soft` 底，12px，占位 `搜索模型…`，左侧 14px 放大镜图标；打开时聚焦，可直接输入 |
| 模型列表 | 最大高 240px，内部滚动；provider 分组标题 12px `--text-muted`，高 24px；模型行高 32px、13px、圆角 6px，悬停 `--accent`；当前模型右侧 16px 勾选 |
| 搜索无结果 | 显示 `没有找到模型`，13px `--text-muted`，上下内边距 12px |
| 分区标签 | `思考强度`：12px / 20px，`--text-muted`，与分段控件间距 6px |
| 档位分段控件 | 外层轨道 `--bg-soft`，内边距 2px，圆角 10px；档位等宽分栏，高 26px，间距 2px，圆角 8px；未选中透明底 + `--text`，选中 `--text` 底 + `--bg` 文字；文字 12px |
| 档位文案 | 与触发现有文案一致：`关闭`、`低`、`中`、`高`、`极高`、`最大`、`极致`，只显示模型支持的档位 |
| 档位行为 | 点击立即切换并关闭浮层；`role="radiogroup"`，当前档位为唯一 Tab 停靠点，←/→ 移动焦点，Enter / Space 选中 |
| 模型行为 | 点击选择并关闭；每次打开重置搜索并回到列表顶部 |
| 无 reasoning | 模型不支持思考档位时不渲染分隔线、标签和分段控件，浮层只有模型区 |
| 关闭 | Esc 关闭并把焦点交回入口，不改变任何选择 |

### 配色与适配

- 只用 `--bg`、`--bg-elevated`、`--bg-soft`、`--line`、`--text`、`--text-muted`、`--accent`；选中态用正文色反白，不引入品牌色块。
- `@container/composer` < 32rem：浮层宽 `min(320px, calc(100vw - 24px))`；档位仍单行等宽，文字不截断；统计带按收起规则逐项收起，最少保留 `统计`。
- 无会话、会话未就绪或不可写：入口禁用；内联编辑历史 Prompt 与协作房间不渲染该入口（现状不变）。

## 验证计划

- 统计带宽度贴合内容并居中，底角与卡片关系连续；页面底部总高减少约 10px。
- 运行中与完成后统计显示在信息带内；无数据时整条信息带不出现。
- 宽度收窄时逐项收起，最后保留 `统计`，详情浮层可打开。
- 浮层首屏显示搜索与模型列表，思考档位在列表下方；点击档位一次生效。
- 模型列表滚动时，分隔线与档位区固定在浮层底部。
- 键盘：打开后焦点在搜索框，Tab 到档位组；方向键在档位内移动；Esc 关闭并还原焦点。
- 模型不支持 reasoning 时浮层只剩模型区；窄屏（< 768px）浮层不超出视口。
