# 输入区紧凑化与思考档位直达（2026-10-27）

对象：`packages/web` 底部输入区。
状态：已实现，并在开发实例 `http://127.0.0.1:2420` 核对。

## 问题

1. 入口 → `思考强度` 行 → 档位，切一次档需要 3 次点击，且每次打开都从入口行开始。
2. 统计信息带高度约 50px，视觉重量超过内容本身。

## 已确认的决定

| 对象 | 决定 |
| --- | --- |
| 浮层结构 | 首屏直接是搜索行与模型列表；`思考强度` 在列表下方，固定贴浮层底部 |
| 思考档位 | 用工作台页签组件（`Tabs` + `WorkbenchTabBar`），点击或键盘选中即生效并关闭浮层 |
| 模型列表 | 选择后关闭浮层；保留搜索、provider 分组和当前项勾选 |
| 会话统计 | 保留信息带形态、全宽与共边关系；高度 50px → 38px，底色 25% → 15% |

## 规格

### 收起态：输入卡片

| 对象 | 规格 |
| --- | --- |
| 卡片 | 宽与对话区一致（最大 1280px），圆角 48px（支持 `corner-shape` 时 squircle），边框 0.5px `--line`，底色 `--bg`，阴影 `0 2px 12px rgb(0 0 0 / 0.05)` |
| 内部顺序 | 运行状态行 → Prompt 输入区（14px / 20px）→ 工具行（h-8，上下内边距 8px） |
| 工具行 | 左端附件按钮；右端 ContextRing → 模型与思考入口 → 快速模式 → 发送 / 停止按钮，顺序与尺寸不变 |
| 有信息带时 | 输入卡片底角为直角，与统计信息带共边 |

### 统计信息带

| 对象 | 规格 |
| --- | --- |
| 位置 | 输入卡片正下方，全宽，与卡片共边（`margin-top: -1px`，共用一条边框） |
| 高度 | 38px：上下内边距 4px + 条目高 28px + 上下边框 |
| 圆角 | 上边不设圆角；底角 48px（支持 `corner-shape: squircle` 时沿用） |
| 表面 | `--muted` 15% 底色，1px 边框 `--line`，阴影 `0 2px 12px rgb(0 0 0 / 0.05)` |
| 内容 | 四项居中：`平均 TPS`、`缓存命中`、`输入`、`输出`；12px，标签 `--text-muted`，数值 `--text` + 等宽数字 |
| 条目 | 行高 28px，左右内边距 6px，条目间距 2px；不加分隔符号 |
| 收起 | 宽度不足时按现有机制逐项收起，优先保留 `平均 TPS`；未显示的指标通过行尾 `统计` 入口查看 |

### 展开态：模型与思考强度浮层

| 对象 | 规格 |
| --- | --- |
| 外壳 | 宽 320px，`side="top"`、`align="end"`、`sideOffset=8`；圆角 16px，边框 0.5px `--line`，阴影 `0 8px 28px rgb(0 0 0 / 0.12)`，无内边距 |
| 搜索行 | 高 32px，左右各留 8px、上留 8px、下留 4px；圆角 8px，底 `--muted`，放大镜 14px，占位 `搜索模型…`，12px；打开浮层时聚焦 |
| 模型列表 | 最大高 240px，内部滚动，底部 14px 渐隐遮罩；provider 分组标题 12px `--text-muted`、高 28px；模型行高 32px、13px、圆角 6px，选中项 `--accent`，当前模型右侧 16px 勾选 |
| 分区 | 列表下方 0.5px `--line` 分隔线，再接档位区；档位区固定在浮层底部，不随列表滚动 |
| 档位标签 | `思考强度`，12px / 20px，`--text-muted`，与轨道间距 6px |
| 档位轨道 | `WorkbenchTabBar`：高 34px，圆角胶囊，`--bg-card` 90% 底、0.5px 边框、`0 2px 8px rgb(0 0 0 / 0.06)`，内边距 2px |
| 档位项 | 高 28px，等宽分栏（`min-w-0` + `flex-1`），13px；未选中 `--text-muted`，悬停与选中由轨道内滑动高亮（`--primary` 7%）和正文色文字表达；文字在各自档位内水平居中；当前项是唯一 Tab 停靠点 |
| 档位文案 | `关闭`、`低`、`中`、`高`、`极高`、`最大`、`极致`，只显示模型支持的档位 |
| 交互 | 点击档位或模型即生效并关闭浮层；`←` / `→` / `Home` / `End` 在档位组内移动焦点，`Enter` / `Space` 选中；`Esc` 关闭并把焦点交回入口；每次打开重置搜索并回到列表顶部 |
| 无 reasoning | 不渲染分隔线、标签和档位区，浮层只有模型区 |
| 键盘隔离 | 档位区的方向键、`Home`、`End`、`Enter`、`Space` 不冒泡给 cmdk，避免同时移动模型列表选中项 |

### 适配

- 浮层宽 `w-80`，受 `max-w-[calc(100vw-2rem)]` 约束；档位等宽分栏，文字不截断。
- 统计带按现有宽度规则逐项收起，最少保留 `统计` 入口；信息带始终全宽。
- 无会话、会话未就绪或不可写时入口禁用；内联编辑历史 Prompt 与协作房间不渲染该入口（现状不变）。

## 实现位置

- `src/components/workbench/composer-runtime-settings.tsx`：浮层结构、搜索行、模型列表、档位 `Tabs` + `WorkbenchTabBar`、键盘隔离。
- `src/components/workbench/composer.tsx`：浮层打开/关闭与搜索状态、`/model` 命令直接打开浮层、统计带高度与底色。
- `DESIGN.md` §5.7：同步本方案。

## 已验证（开发实例 http://127.0.0.1:2420）

- 统计带实测高 38px，上下内边距 4px，底色 `--muted` 15%，底角 48px；输入卡片底角让出，共边连续。
- 打开浮层后焦点在搜索框；输入 `glm` 后列表只剩 `Glm 5.3 Flash`，档位不被过滤。
- 点击档位立即生效并关闭浮层，入口文案同步更新。
- 点击模型切换生效并关闭浮层，入口同步更新。
- 键盘：`Tab` 进入档位组并落在当前档位；`ArrowRight` 把焦点移到下一档；`Enter` 选中、关闭浮层并把焦点交回入口。
- 档位文字居中：6 档实测每个 48px 等宽，文字左右间距相等（18/18、12/12）；无图标页签不再保留图标间距，文字不再右偏。
- `Esc` 关闭浮层并把焦点交回入口。
- `npm run check` 通过。
