# LYStar TUI Design

## 产品与任务

LYStar TUI 是高频终端 Agent 工作台。用户需要连续扫描回答、Tool 状态、文件路径、错误、Diff 和 Subagent 进度，并快速展开当前关心的详情。

## 视觉方向

- 使用平面、高密度、连续阅读结构。
- 设计感来自信息层级、文字排版、状态色、细分隔线和稳定对齐。
- Tool、Turn Summary 和系统过程卡片不使用大面积状态背景。
- 用户消息、输入框、Overlay 和真正需要边界的工具继续保留现有表面结构。

## 识别点

每张过程卡片左侧只使用一个语义图标，最右侧使用 `▸/▾` 表示展开状态。相邻 Tool 由低对比灰色细线连续分隔，线的上下不插入空白行。

## 颜色角色

- `text`：主要动作和正文。
- `muted`：路径目录、次要信息和输出。
- `dim`：耗时、弱提示和非活动状态。
- `success`、`warning`、`error`：只标状态和关键数字，不铺背景。
- `accent`：文件名、链接、当前活动和输入焦点。
- `toolDivider`：Tool 与 Agent 行之间的低对比细线；缺失时回退 `borderMuted`。

## 密度与布局

- Tool 标题使用一至两行：第一行动作、状态和展开符，第二行放路径、命令、查询或对象摘要。
- Tool 列表内部没有空行；展开的多命令组只在组标题与第一条命令之间保留一行层级间距，分隔线本身占一行。
- 内置工具使用统一的 Unicode/emoji 语义图标；无法稳定显示 Unicode 的 Windows 外部终端使用 ASCII 降级。
- Assistant 正文与 Tool 列表之间可以保留一个空行。
- 所有宽度来自 `render(width)`；ANSI、OSC 8、中文和宽字符按可见宽度计算。
- 宽度不足时依次删除耗时、Provider、完整目录等次要信息，动作、状态、错误、basename 和展开符必须优先保留。

## 交互

- 卡片标题、摘要和普通详情行切换当前卡片。
- 鼠标悬浮使用 `selectedBg` 标出当前命中的 Tool 卡片，空行和分隔线不响应 Hover。
- 滚轮先归一化为逻辑行：独立滚轮按 3 行移动，高频触控板和手机事件按间隔累计；方向反转立即清空旧余量，鼠标渲染合并到 60 FPS。
- 链接优先于卡片点击。
- 分隔线不响应点击。
- `Ctrl+O` 递归展开或收起当前已渲染卡片。
- 输入框优先使用终端原生闪烁细线光标，不支持时保留终端默认降级。
- Subagent 外层控制 Agent 列表；每个 Agent 行控制自己的详情；打开 Agent 会话使用独立行。

## 响应式

- `>= 100`：显示完整两行布局和右侧统计。
- `72-99`：保留两行，路径中间省略。
- `50-71`：压缩次要元数据，保留 basename 和状态。
- `< 50`：最小一至两行，保证图标、动作、状态和展开符不冲突。

## 保持项

- `WorkspaceComposer` 的结构、尺寸、品牌切口和模型信息。
- Session JSONL、Provider 数据、Tool 名、Extension API、RPC 和 Subagent 参数枚举。
- OSC 8 链接、图片、Diff、第三方 Extension 和历史 Session 重放。

## 不做

- 左侧时间线。
- 自动生成任务阶段标题。
- 发光、阴影、渐变、装饰背景和大块状态底色。
- 卡片内再绘制背景卡片。
- 依赖 Nerd Font 或私有区字符。
- 为图标和卡片样式增加用户配置。
