# LYStar Code GUI 组件规范

> 日期：2026-08-13

## 基础尺寸

| 项目 | 规格 |
|---|---:|
| 基础网格 | `4px` |
| 侧栏默认宽度 | `320px` |
| Inspector 默认宽度 | `520px` |
| 项目行高度 | `44px` |
| Session 行高度 | `36px` |
| Tool 行最小高度 | `48px` |
| 普通控件高度 | `36px` |
| 图标 | `16px` |
| 最小命中区 | `32×32px` |
| 普通圆角 | `6px` |
| 容器最大圆角 | `8px` |
| Composer 圆角 | `12px` |

## 侧栏

### 品牌区

- 使用原始 LYStar Mark 与 `LYStar Code` 名称。
- Logo 高度 `24px`，品牌区高度 `56px`。
- 浅色和深色使用各自品牌资产，不用 CSS 滤镜反色。
- 搜索、通知和主题菜单使用图标按钮，命中区 `32px`。

### 项目列表

项目只有一个连续列表，不出现“本机项目”“SSH 项目”两个分组标题。

| 类型 | 左侧 | 中间 | 右侧 |
|---|---|---|---|
| 本机项目 | Folder 图标 | 项目名称 | 空 |
| SSH 项目 | FolderSymlink 或带远程语义的 Folder 图标 | 项目名称 | 连接名 + 状态点 |

规则：

- 项目排序：置顶优先，其次按 `lastOpenedAt` 倒序。
- 当前项目使用 `surfaceSelected`；Hover 使用 `surfaceHover`。
- 当前项目下展开最近 Session；Session 内容缩进 `28px`，行背景和操作区保持项目列表全宽；其他项目不展开。
- 项目名 `14px / 500`，连接名 `13px / 400`。
- 项目名优先完整显示；先截断连接名，再截断项目名。
- 本机项目不得出现状态点、主机名或“本机”标签。
- SSH 状态：在线、重连中、失败、离线；状态点之外提供 Tooltip 和 `aria-label`。

### Session 行

- 高度 `36px`，左侧文档/会话图标 `14px`。
- 当前 Session 使用更明确的选中表面；Hover 不能覆盖当前项目层级。
- 标题单行省略，Tooltip 显示完整标题。
- 最近 Session 只在当前项目下显示，最多 20 条并允许“展开显示”。
- Session 状态位于右侧状态区，不占用标题前方；Hover 和选中背景与项目行等宽。
- 侧栏支持展开/收起并持久化。展开宽度 `288-360px`，收起后主内容保留 `32×32px` 展开按钮。

## 顶栏

- 高度 `56px`，单行稳定布局。
- 左侧：项目 / Session。
- 中部可显示 SSH 连接名和 Git 分支，有事实值时才显示。
- 右侧：“变更”命令和图标操作。
- 窄宽度依次隐藏连接名、完整路径和次要图标，项目、Session、变更入口必须保留。

## 对话

### 用户消息

- 右对齐，最大宽度 `72%`。
- 使用 `surfaceSubtle`，圆角 `8px`，内边距 `12px 16px`。
- 长文本按正文规则换行，不能缩小字号塞入容器。

### Assistant

- 不使用卡片背景。
- 正文 `15px / 1.65`，最大阅读宽度 `1120px`。
- 段落、列表、代码块和 Tool 保持连续阅读节奏。

### Thinking

- 默认折叠为一行，高度 `36px`。
- 显示状态、耗时和展开符；不显示完整思考正文预览。

## Tool

- 使用平面边框容器或连续行，不使用彩色卡片。
- 标题行：图标、动作、对象摘要、状态。
- 路径和命令使用等宽字体与 `textSecondary`。
- 状态色只用于图标和状态文字。

| 状态 | 表现 |
|---|---|
| 等待 | Muted 图标与文字 |
| 运行中 | Accent spinner，允许进度文字 |
| 已完成 | Success 图标与文字 |
| 失败 | Error 图标、错误摘要直接可见 |
| 已取消 | Muted 图标与明确“已取消” |

## 文件变更

- 摘要标题“已编辑 N 个文件”，显示总 `+/-`。
- 文件行高度 `40px`，路径左对齐，增删数右对齐。
- 默认显示前三项；更多项使用“再显示 N 个文件”。
- “撤销”“审阅”属于明确命令，可以使用文字按钮。

## Composer

- 固定在主内容底部，常规高度 `140-190px`，最多 `280px`。
- 输入区占主要空间，默认无工具栏分隔线。
- Placeholder：`输入任务或继续说明`。
- 左下：`+` 操作菜单；只有需要用户处理时才显示权限/信任状态。
- 右下：模型与思考强度的单一入口，以及一个圆形发送/停止按钮。
- 模型菜单一级选择模型、二级选择思考强度；不显示成多个 Select 框。
- 图片支持文件选择、剪贴板粘贴和拖放，三种入口共用同一校验、缩略图和移除逻辑。
- 连接归属来自当前项目，Composer 不放连接选择器。

| 状态 | 主按钮 | 输入行为 |
|---|---|---|
| 空 | 禁用发送 | 可输入 |
| 聚焦 | 发送箭头 | 焦点环仅包围 Composer |
| 运行中 | 停止图标 | 允许引导/后续输入 |
| 等待交互 | 发送箭头 | 显示待处理 UI，不清空草稿 |
| Session 被锁 | 禁用发送 | 显示“该会话正在其他进程中使用” |

## Inspector 与 Diff

- 常规工作台默认关闭，点击“变更”后打开。
- 宽屏并排，窄屏覆盖；不是主会话里的嵌套卡片。
- Tab 只有“本轮文件”“工作区变更”。
- 文件树支持筛选、展开、选中和修改状态。
- Diff 使用等宽字体、行号、增删标记、轻量底色。
- Inspector 默认宽 `520px`，范围 `420-680px`。

## 设置控件

- Boolean 使用 Toggle；多选使用 Checkbox；枚举使用 Select；模式使用分段选择或可视选项。
- 设置行最小高度 `64px`，左侧标题和说明，右侧控件。
- 设置分组使用连续列表和分隔线；只有需要共同边界的状态组使用单层容器，禁止卡片套卡片。
- 分类：个性化、外观、连接、模型与认证、Skill、自动更新、诊断、关于。
- 设置侧栏顶部包含 Host 选择器：`所有设置`、本机和每个 SSH Host。Host 切换不影响当前工作区连接和 Session。
- 个性化/指令页使用单一大编辑器。顶部选择 Host 全局指令或该 Host 下的项目；继承文件和路径进入“生效来源”详情。
- 设置侧栏宽 `280-320px`；内容区最大宽度 `1280px`，页面操作与标题同行，页面内搜索位于列表上方。

### 连接与远端目录

- SSH 表单先选择 SSH Config alias 或直接连接。直接连接字段为主机、用户、端口、认证方式和远端系统；认证方式使用 Agent/私钥/密码单选或分段控件。
- 私钥通过系统文件选择器选择；密码输入不回显。“记住密码”只允许写系统凭据库，`desktop-state.json` 只保存凭据引用。
- 未知 Host key 弹窗显示主机、端口和全部 SHA-256 指纹，主动作是“信任并继续”，取消不修改 `known_hosts`。
- 远端目录浏览器包含面包屑、Home、上级目录、刷新、隐藏目录开关、目录列表和“选择当前目录”；路径由 Host 返回，GUI 不拼接远端 Shell 命令。
- SSH 长表单和目录列表使用弹窗内部滚动。`800×600` 下弹窗四边至少保留 `16px`，Header、关闭按钮和底部操作始终可达。

### 模型与认证

- Provider 行最小高度 `72px`，显示 Provider 名称、认证状态、凭据来源和可用模型数量。
- 状态使用“已连接”“需要认证”“环境变量”“运行时临时凭据”等用户可理解文案；技术来源值只放在详情或 Tooltip。
- 行级动作只有“登录”“重新认证”“退出”或“查看模型”，同一时刻只显示当前可执行动作。
- OAuth 登录由系统浏览器完成，WebView 只显示等待、成功、取消和错误；API key 使用密码输入并直接提交后台，提交后不回显。
- 模型列表支持 Provider 筛选和搜索，显示模型名称、ID、能力与可用状态；默认模型和 Composer 当前模型使用同一 Runtime 事实源。

### Skill

- 页内 Tab：`全部`、`用户`、`项目`；数量来自当前发现结果。内置资源只有 Runtime 确实返回该作用域时才增加 `内置` Tab。
- 搜索匹配名称和描述。列表是连续行，不用 Skill 卡片墙。
- Skill 行最小高度 `76px`：左侧统一 Skill 图标，中间名称与最多两行描述，右侧作用域、状态和 Toggle。
- 用户级 Skill 显示“用户”；项目级 Skill 显示当前项目名或“项目”。路径、Package source 和诊断只在展开详情中显示。
- Toggle 修改对应作用域的资源 override，刷新后以 `PackageManager.resolve()` 的 `enabled` 结果回查；项目 Skill 受 Project Trust 限制时禁用开关并给出信任动作。
- 解析失败或名称冲突不能只显示关闭状态；行内显示错误摘要，详情列出 `ResourceDiagnostic`，并提供“打开所在目录”或“重新加载”。
- 首版不提供市场、评分、下载量、远程目录浏览，也不把 Extension、MCP 或 Prompt Template 塞进 Skill Tab。

### 自动更新

- 页面顶部先显示结论：`已是最新版本`、`可更新`、`等待任务结束`、`需要系统操作`、`更新失败` 或 `离线未检查`。
- 主区域只保留当前版本、目标版本、进度、阻塞原因和一个当前动作；没有更新时不展示空的升级步骤。
- 下载或安装中显示单条总进度和当前步骤，后续步骤用简短文本列出，不同时展开三个组件面板。
- `更新详情` 默认折叠，展开后显示 GUI、Bundled Runtime、TUI、远端 Host、signature、`setVersion`、upgrade path 和最近检查时间。
- 强制验签、防回放和兼容路径没有关闭开关，也不提供任意版本选择器。

### 诊断

- 首屏分为“需要处理”和“检查项目”。异常按严重程度排序，包含影响、当前状态和唯一下一动作。
- 没有异常时显示“未发现需要处理的问题”，不再用大面积绿色表格重复正常状态。
- 检查项目分为本机、连接与远端、Session 与任务、更新安全；分类行显示最差状态和数量，默认折叠正常明细。
- 单项展开后才显示版本、Protocol、IPC、锁、journal、signature 等技术值。错误和 warning 保持行内可见，不能只靠 Toast。
- 页级动作是“重新检查”和“导出诊断包”；日志目录、配置目录和脱敏说明放在页面底部。

### 关于

- 顶部使用真实 LYStar Mark、`LYStar Code`、GUI 版本和一句产品描述。
- 版本列表显示 GUI、Bundled Host、Bundled Runtime、GUI Protocol 和检测到的官方托管 TUI；远端 Host 不在关于页枚举。
- 操作入口：发行仓库、检查更新、查看许可证、打开配置目录、打开日志目录、复制版本信息。
- 明确显示“Pi 基线”和当前发行仓库；版本与仓库必须来自构建 manifest 或 `piConfig`，不能手写到组件中。
- 不显示营销指标、更新路线图、账号、遥测统计或捐赠入口。

## 窄窗口

- `720-899px` 默认关闭侧栏，顶栏显示汉堡按钮。正式 `800×600` 页面基线必须是抽屉关闭的工作态。
- 抽屉打开态宽 `288px`，从左侧覆盖主内容；遮罩只负责关闭抽屉，不让背景内容承担可读任务。
- 顶栏高度 `48px`，保留项目、Session 和变更入口；连接名、分支和次要图标按优先级隐藏。
- 正文左右内边距 `20-24px`，用户消息最大宽度放宽到 `84%`，Assistant 继续无边框。
- Composer 固定底部，高 `112-132px`；输入区和底部操作分两行，附件、模型文字和圆形发送/停止按钮保留。
- Inspector、项目抽屉和设置覆盖层同一时刻只允许一个打开。

## 反馈与系统状态

| 状态 | 文案示例 | 动作 |
|---|---|---|
| 空会话 | 暂无会话 | 新建会话 |
| 连接失败 | 连接失败 | 重新连接 |
| 重连中 | 正在重新连接 | 取消重连 |
| Session 锁定 | 该会话正在其他进程中使用 | 只读查看 / 重试 |
| 更新需授权 | 需要完成系统授权 | 继续 |
| Tool 失败 | 显示真实错误摘要 | 展开详情 / 重试 |

错误不能只靠 Toast；影响当前任务的错误必须留在对应 Tool、连接或 Session 区域。

Toast 只用于短暂结果和非阻塞提示，位于顶栏下方；层级低于 Composer、侧栏、菜单、设置和模态弹窗。Toast 不得覆盖关闭按钮、模型菜单、Composer 菜单或表单操作区。

## 键盘与可访问性

- 所有图标按钮有 Tooltip 和可访问名称。
- Focus ring 宽 `2px`，使用 `focusRing` Token。
- 最小命中区 `32px`，主要发送/停止按钮 `40px`。
- 状态色不是唯一信息载体。
- `prefers-reduced-motion` 下关闭位移和循环动画。
- 中文、长项目名、长连接名和长模型名必须经过溢出测试。
