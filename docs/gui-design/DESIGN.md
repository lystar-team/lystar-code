# LYStar Code GUI 设计方向

> 状态：视觉方向确认稿
>
> 日期：2026-08-13
>
> 适用范围：LYStar Code 桌面 GUI

## 产品与核心任务

LYStar Code GUI 是跨平台编码 Agent 工作台。用户需要在同一个窗口中管理本机与 SSH 项目、持续对话、监督 Tool、恢复远程任务、查看 Session 历史并审阅文件变更。

界面首先服务扫描、输入、状态判断和连续操作。视觉质感来自秩序、密度、排版、边界和反馈，不依赖装饰性背景。

## 视觉方向

- 使用 Codex GUI 式安静、中性、高密度工作台结构。
- 同时提供浅色、深色和跟随系统三种主题模式。
- 浅色与深色共用布局、字号、间距、圆角、组件结构和状态语义。
- 两套主题分别校准表面层级、文字对比、边框、阴影和代码颜色，禁止简单反相。
- 保持连续阅读：Assistant 正文不放入卡片；用户消息、Tool、Diff、Composer 和 Inspector 只在需要边界时使用表面容器。

## 识别点

左侧连续项目列表与中间 Tool / Diff 工作流共同形成 LYStar 的识别。项目不按本机和 SSH 拆组：本机项目保持纯净目录行，SSH 项目在右侧标明连接名和状态点，当前项目的 Session 直接在项目下展开。

## 主题模式

| 模式 | 行为 |
|---|---|
| 跟随系统 | 默认值，监听操作系统主题变化并即时切换 |
| 浅色 | 固定使用浅色 Token，不跟随系统变化 |
| 深色 | 固定使用深色 Token，不跟随系统变化 |

主题切换只改变语义 Token，不改变组件尺寸、信息层级和功能入口。用户选择持久保存；首次启动使用跟随系统。

## 结构与密度

- 设计基准画布为 `2816×1640`，默认窗口不得小于 `1280×800`。视觉稿必须以完整单窗口呈现，禁止为了同时展示双主题而横向压缩主界面。
- 桌面默认左侧栏宽度 `320px`，允许在 `288-360px` 内调整；主内容保持舒展的连续阅读宽度，右侧 Inspector 默认 `520px`，允许在 `420-680px` 内拖动。
- 顶栏、侧栏项目行、Session 行和 Tool 行使用稳定高度，动态内容不得推动整体布局跳动。
- 默认间距以 `4px` 为最小单位，主要节奏使用 `8 / 12 / 16 / 24px`。
- 圆角只使用 `4 / 6 / 8px`；Composer 最大 `12px`，不使用胶囊容器。
- 边框和分隔线承担主要分组，不使用大面积阴影分隔普通区域。
- 用户消息右对齐，最大宽度 `72%`；Assistant 正文使用无边框连续布局。

## 项目与 Session

- 侧栏只有一个“项目”列表，本机项目和 SSH 项目按置顶、最近打开时间连续排列。
- 本机项目行：目录图标、项目名；右侧不显示主机、状态点或“本机”标签。
- SSH 项目行：远程目录图标、项目名；右侧显示保存的 SSH 连接名和状态点。
- SSH 连接名是项目归属信息，不单独形成项目分组；多个项目可以显示同一个连接名。
- 当前项目的最近 Session 直接在项目行下缩进展开。只展开当前项目，避免长侧栏同时打开多组 Session。
- 当前项目使用低对比选中表面；当前 Session 在缩进层级中使用更明确的选中状态。
- 项目名优先于连接名；宽度不足时先压缩或截断连接名，状态点始终可见。
- 本机项目不显示连接状态。绿色、黄色、红色和灰色状态点只服务 SSH 连接。

## 色彩原则

- 中性灰承担背景、表面、文字和边框，避免蓝紫、米黄或单一色相统治界面。
- 品牌与交互强调使用克制的清蓝色，主要用于链接、焦点和当前选择。
- 在线与成功使用青绿色；警告使用琥珀色；错误和删除使用红色。
- 状态色优先用于图标、文字、细边框和数字，不铺大面积彩色背景。
- Diff 增删色在浅色和深色主题分别校准，不能只复用同一 RGB 值。
- 所有正文、次要文字、禁用状态、边框和焦点环必须满足可访问对比要求。

## 字体与排版

- 界面字体使用系统 UI 字体栈，中文优先系统原生黑体，避免额外下载字体。
- 代码、路径、命令和模型 ID 使用系统等宽字体栈。
- 正文基准 `15px / 1.65`，紧凑控件 `13px / 1.4`，普通控件 `14px / 1.4`。
- 页面内不使用营销式超大标题；工作台标题最大 `18px`。
- 字重主要使用 `400 / 500 / 600`，依靠层级和对比组织信息。
- 字母间距统一为 `0`。

## 组件几何

- 图标按钮使用 Lucide 图标，标准尺寸 `16px`，按钮命中区不小于 `32px`。
- 文本按钮只用于明确命令；撤销、重做、复制、关闭、展开等使用熟悉图标并提供 Tooltip。
- Tool 与 Diff 使用平面容器和细边框，不嵌套装饰卡片。
- 输入、选择器、菜单、弹窗和 Inspector 使用同一套表面、边框、焦点环和禁用语义。
- 选中项使用低对比选中表面、左侧强调或清晰文本层级，不使用廉价下划线。
- Composer 固定在主内容底部，1 至 8 行增长，桌面常规高度约 `140-190px`。
- Composer 主体是一块干净输入面。底部左侧只有附件和当前确实需要处理的权限/信任状态；正常状态不显示多余标签。
- Composer 底部右侧以紧凑文本显示模型和思考强度，点击文字打开菜单，不渲染为多个并排 Select。
- Composer 右下只有一个圆形发送/停止主按钮。发送、停止、不可用三种状态使用同一稳定命中区。
- 连接来自当前项目，Composer 内不再提供连接选择器。
- 模型、思考强度和发送控制不得压缩输入文字，也不得形成独立工具栏视觉。

## Inspector 与审阅

- 常规工作台默认不强制打开 Inspector，主会话保持舒展。
- 点击“变更”后，Inspector 从右侧并排打开；宽度不足时覆盖主内容。
- Inspector 顶部使用轻量标签或标题栏，下方是 Diff 主区和文件树，不在主会话里再嵌套完整 Diff 工作台。
- Diff 行号、增删底色、文件路径、筛选和文件树参考成熟代码审阅工具，但只显示 LYStar 方案已有的本轮文件和工作区变更。

## 设置页

- 使用左侧设置分类和右侧连续设置组，延续主应用的表面、字号和边界。
- 分类固定为：通用、外观、连接、模型与认证、Skill、自动更新、诊断、关于；“能力”可作为 Skill 的导航分组标题，不增加独立页面。
- 设置内容区使用统一最大阅读宽度和页内节奏：标题、必要说明、页面级操作、连续列表。普通设置行不做 Dashboard，不用三列卡片概览。
- 模型与认证按 Provider 组织，展示认证状态、凭据来源、可用模型和登录/退出动作。API key、OAuth token 和 `auth.json` 内容不得进入 WebView；OAuth 只通过系统浏览器完成。
- Skill 页面参考成熟插件设置的 Tab、搜索、连续列表和行级开关，但只管理 Runtime 已发现的 Skill。展示名称、描述、来源、作用域、启用状态和诊断；不伪装成市场，不把 Extension 或 MCP 混入 Skill 数量。
- 自动更新先显示当前结论和唯一下一动作，再显示目标版本、进度和阻塞；签名、防回放、组件顺序和完整升级路径默认收进“更新详情”。
- 诊断先列“需要处理”，没有异常时显示清楚的健康结果；正常项按本机、连接与远端、Session 与任务、更新安全折叠，单项展开后再显示版本和技术明细。
- 关于页以 LYStar 品牌、产品版本和运行组件版本为主，提供发行仓库、许可证、配置目录、日志目录和诊断入口；不放营销文案、账号信息或遥测图表。
- 不照搬参考图中的语音、宠物、浏览器、电脑操控、Worktrees、插件市场等 LYStar 首版未规划能力。
- 二元设置使用 Toggle，主题使用“跟随系统 / 浅色 / 深色”三段选项，枚举使用 Select。

## 品牌

- 窗口侧栏顶部使用 LYStar 原始 Logo 资产与 `LYStar Code` 名称，不由生成模型重绘 Logo。
- 浅色主题使用黑色 Logo；深色主题使用白色 Logo；蓝色星芒保留品牌原色。
- `brand/lystar-mark-light.png` 与 `brand/lystar-mark-dark.png` 是原始母版；界面实现优先使用从母版导出的透明底 `brand/lystar-mark-on-light.png` 与 `brand/lystar-mark-on-dark.png`。
- 透明底衍生资产只能通过去除母版纯白或纯黑底色生成，不能修改 Mark 轮廓、星芒、比例或颜色。若衍生图边缘不满足实装质量，回到母版重新导出，不从页面设计图裁切。
- 空间紧张时只显示 Logo 标记，完整名称用于正常宽度侧栏、关于页和安装产物。
- Logo 周围保留至少一个星芒宽度的安全区，不裁切环形轨迹，不添加阴影、渐变或发光。

## 动效

- 动效只表达连接、展开、面板切换、流式状态和操作结果。
- 常规过渡 `120-180ms`，面板进入 `180-220ms`。
- 不使用弹性动画、持续漂浮、发光呼吸和装饰性粒子。
- `prefers-reduced-motion` 下关闭位移和循环动画，只保留必要状态变化。

## 响应式

| 宽度 | 行为 |
|---:|---|
| `>= 1200px` | 左侧栏与主内容并排，Inspector 可并排 |
| `900-1199px` | Inspector 覆盖主内容 |
| `720-899px` | 左侧栏默认关闭，由汉堡按钮打开临时抽屉 |
| `< 720px` | 只保留主内容，项目和设置从菜单打开 |

`800×600` 正式基线展示抽屉关闭的可工作状态：顶栏、会话正文和固定 Composer 都必须完整可用。抽屉打开时宽 `288px`，覆盖主内容并使用轻量遮罩；它是单独交互状态，不能与完整正文同时作为页面基线，也不能压缩成永久窄侧栏。窄窗口 Composer 重新排布为约 `112-132px` 高，模型文字允许截断，但附件和单一发送/停止按钮必须保留。

浅色、深色必须在相同宽度下保持完全一致的布局和组件尺寸。

## 保持项

- LYStar 中文产品身份。
- 单一项目列表、本机与 SSH 行级差异、Session、Tool、Diff、Composer 和 Inspector 的真实结构。
- 青绿在线状态、蓝色链接、红黄异常和 Diff 增删语义。
- TUI 已建立的高密度、连续阅读、细分隔线和稳定对齐原则。

## 避免项

- 把产品默认方向限定为深色。
- 渐变、玻璃、发光、渐变球、噪点和装饰背景。
- 营销式 Hero、Bento、三列指标卡和展示型大留白。
- 卡片套卡片、大圆角、全胶囊控件和大面积状态底色。
- 假项目、假任务、假趋势和系统不存在的功能入口。
- 浅色主题直接由深色主题反相得到。
- 把本机项目和 SSH 项目拆成两个视觉分组。
- 在 Composer 内堆放连接、权限、模型、思考强度等多个大号下拉框。
- 为同时展示双主题而压缩窗口比例或让侧栏、会话区、Inspector 发生形变。
